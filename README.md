Este repositorio contiene la versión **modificada y asistida con Inteligencia Artificial** del proyecto M2Cinema.  
El objetivo es mostrar cómo el uso de agentes y técnicas de IA puede optimizar el desarrollo, la organización y la revisión del código.

## 🚀 Tecnologías utilizadas
- **Backend**: Express 5, Mongoose 8,dotenv, cors, morgan
- **Base de datos:** MongoDB  
- **Frontend:** Next.js  
- **Control de versiones:** Git/GitHub  
- **Agentes de IA:** Coordinador, Implementador y Review (OpenCode)  
- **RAG básico:** integración de búsqueda y generación para enriquecer respuestas con datos externos.  
- **Context 7:** nivel de contexto extendido para mantener coherencia en la planificación y ejecución.  

## 📌 Características principales
- CRUD completo de películas (crear, listar, actualizar, eliminar).  
- Endpoints REST organizados con controladores y servicios en NestJS.  
- Persistencia con MongoDB para películas y usuarios.  
- Arquitectura modular y escalable, siguiendo buenas prácticas.  
- Planificación en modo **Plan** y ejecución en modo **Build** con OpenCode.  
- Uso de RAG para enriquecer consultas y respuestas.  
- Documento **evolución**: memoria del proyecto donde se registran cambios, mejoras y decisiones tomadas durante el desarrollo asistido con IA.  

## 🏗️ Objetivo
Construir una aplicación de películas con funcionalidades CRUD, búsqueda y detalle, integrando mejoras sugeridas por agentes de IA y manteniendo un backend sólido con MongoDB.
