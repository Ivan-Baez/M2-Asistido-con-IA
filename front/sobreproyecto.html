🎯 Objetivo del Proyecto

Este proyecto fue desarrollado como parte del módulo 2 de la formación Full Stack en Henry. El objetivo es aplicar conceptos de frontend, backend y base de datos para crear una plataforma interactiva sobre películas.

🛠️ Tecnologías Utilizadas

  • HTML, CSS y JavaScript
  • Node.js y Express
  • MongoDB y Mongoose
  • Bootstrap 5
  • Axios y manejo de rutas

💡 Motivación Personal

El cine siempre fue una fuente de inspiración. Este proyecto combina mi pasión por la tecnología con el arte de contar historias. Cada componente fue pensado para ser modular, eficiente y visualmente coherente.
